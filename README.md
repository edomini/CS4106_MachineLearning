# CS4106 Group Project Guide

## Using Kaggle and Google Colab

For this project, each group will be assigned a dataset, a Kaggle baseline notebook, and a machine learning task. Your job is to:

* Understand the dataset and the task
* Run the assigned baseline
* Improve it in a meaningful way
* Explain what you changed and why
* Submit your final notebook and a short video

---

## 1. What is Kaggle?

Kaggle is an online platform used for machine learning and data science. It is commonly used to:

* Find datasets
* Explore example notebooks
* Compare results on shared problems

For this project, you will use Kaggle to access your assigned dataset and baseline notebook.

---

## 2. What is Google Colab?

Google Colab is an online notebook environment where you can write and run Python code in your browser.

* No installation required
* Notebooks can be stored in Google Drive
* Easy sharing and uploading of `.ipynb` files

---

## 3. What will my group receive?

* A project title
* A Kaggle dataset link
* A Kaggle baseline notebook link
* A baseline model

You must use the dataset assigned to your group.

---

## 4. What is a baseline?

A baseline is a simple starting solution:

* First working model
* Not the final submission
* Must be understood and improved

---

## 5. What is Kaggle used for in this project?

* Open and read your dataset
* Download dataset files
* Open the baseline notebook
* Optionally copy the notebook to experiment

---

## 6. What is Colab used for in this project?

Colab is your main coding environment:

* Upload datasets
* Run Python code
* Test ideas
* Save your final notebook

Colab runtime is temporary — save your work regularly.

---

## 7. How do I download a dataset from Kaggle?

1. Open your assigned dataset page
2. Download the files
3. Keep them together in one folder

---

## 8. How do I use the baseline notebook on Kaggle?

* Read it carefully from top to bottom
* Understand:

  * Data loading
  * Data cleaning
  * Model used
  * Evaluation method

To edit:

* Use **Copy & Edit** on Kaggle

---

## 9. How do I move from Kaggle to Colab?

### Option A: Start on Kaggle

* Copy & Edit the notebook
* Make changes
* Download as `.ipynb`
* Upload to Colab

### Option B: Start on Colab

* Create a new notebook
* Manually copy code you understand

---

## 10. How do I upload data into Colab?

* Use the **Files panel (left side)**
* Click **Upload**
* Select your dataset files

---

## 11. How should I run the notebook?

* Run **one cell at a time**
* After each cell:

  * Check output
  * Understand results

Do not run everything blindly.

---

## 12. Can we copy code from Kaggle?

You may:

* Use the assigned baseline
* Copy parts of it
* Run and adapt it

But you must:

* Understand all code used

### Notes

* `.py` file → can run as a script once understood
* `.ipynb` → run cell-by-cell

### Recommended comment:

```python
# Starting point adapted from the assigned Kaggle baseline notebook
# Further changes made by our group
```

Your group **must add its own improvement**.

---

## 13. What are we expected to improve?

You can improve any part of the ML pipeline:

* Preprocessing
* Missing value handling
* Feature selection
* Feature scaling
* Hyperparameters
* Model choice
* Evaluation
* Error analysis

---

## 14. What makes a good improvement?

A good improvement is:

* Tested
* Clearly explained

You should explain:

* What changed
* Why it changed
* How it was tested
* Whether it improved results

---

## 15. What are we not allowed to do?

Do NOT:

* Copy improved code from other Kaggle notebooks
* Combine multiple notebooks and submit as your own
* Use code you cannot explain
* Present others’ work as your own

You may start from the baseline, but improvements must be yours.

---

## 16. What is the overall aim of the project?

The goal is **not just the highest score**, but to show:

* Understanding of the dataset
* Understanding of the baseline
* Meaningful improvement
* Proper evaluation
* Clear explanation

---

## 17. What should be included in the video?

* Max length: **5 minutes**
* Must include:

  * Task explanation
  * Dataset overview
  * Baseline explanation
  * Your improvement
  * Final results
  * Contributions of each member

All group members must speak.

---

## 18. What if our result is especially strong?

Strong, well-validated improvements may:

* Earn bonus marks
* Lead to extended projects or research opportunities

---

## 19. Recommended workflow

1. Open your assigned task
2. Open Kaggle dataset
3. Download dataset
4. Open baseline notebook
5. Understand it
6. Run it successfully
7. Upload dataset to Colab
8. Build your own notebook
9. Improve the baseline
10. Compare results
11. Explain changes
12. Prepare final notebook and video

---

## 20. Summary

Use the assigned Kaggle dataset and baseline notebook to build a starting model, then use Google Colab to:

* Test ideas
* Improve the model
* Clearly explain your work
